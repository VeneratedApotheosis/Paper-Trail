# LA Hacks 2026 (AI Hackathon, October 2026) - Condensed Brief

## Main Tracks
1. Agentverse (Fetch.ai): build/register agents on Agentverse, discoverable via ASI:One, turn intent into executable outcomes.
2. Model Learning: systems that learn/adapt from data, novel models.
3. Beyond the Digital: embedded AI, hardware, AR/VR, adaptive physical interfaces.
4. Applied Intelligence: practical AI for real-world problems (automation, accessibility, education, healthcare...).

## Company Challenges (prize / hard requirements)
- Fetch.ai ASI:One Agent Challenge: register on agentverse.ai, implement Agent Chat Protocol (ACP), full primary workflow demoable INSIDE asi1.ai chat (no custom frontend), multi-step orchestration/tools, public GitHub repo, submit via Submission Agent + Devpost. Bonus: multi-agent, Payment Protocol, ASI Interactive Cards, error recovery, real-time data. Avoid thin chatbot wrappers.
- Paper Best Designed Hack ($1500/1000/500): design fundamentals, ease of use, personal craft (not obviously AI-generated). Free Paper Pro code LAHACKS26.
- Cognition Best Use of Devin ($5000 Devin credits): creativity, novelty, polish; ambitious scope; Devin builds alongside you.
- Base44 Build Something People Want ($1500/$500): real user + problem, live working Base44 app, learning/iteration evidence, post-weekend potential. Must be built substantially on Base44.
- QNX Best use of QNX ($1000/250/250): embedded system on QNX OS + one open-source AI module from oss.qnx.com.
- Workday Future of Work: AI agent/prototype helping people succeed after joining a company (onboarding, trusted info, tasks, skills, growth).
- Even Realities: Even Hub app for Even G2 smart glasses, theme "Quiet Tech" (info quietly in line of sight, stays in background until useful). Any AI models.
- StepFun Step 5 Preview: app/agent MUST call step-5-preview; judged on task completion, reliability, user understanding/control.
- Photon 2.0 (beta live Oct 15, 2026): messaging/calling agent over iMessage/SMS/RCS/WhatsApp/Telegram/email/phone. Prizes: iMessage winner $700, runner-up $300, Best Voice Agent $400. Voice runs on SMS number via SIP to Retell/ElevenLabs/LiveKit/Twilio. Judged on vision, craft, depth, traction; cross-channel memory, human-in-loop, safety fallbacks.
- Visa Future of Shopping ($2000 1st): GenAI commerce (discovery, decision, personalization, checkout, payments, loyalty, post-purchase). Criteria: Innovation 25, UX 25, Technical 20, Commerce impact 15, Trust & responsibility 15.
- Sentry Best Use: use Sentry + at least 2 products beyond errors (Session Replay, Logs, Tracing, Profiling, Uptime, MCP/AI agent monitoring); show how observability shaped build. Prize: guaranteed interviews.
- Espressif Best Use: Espressif (ESP32) hardware creatively; prizes ESP-VoCat / M5Stack Stopwatch.
- Intuit QuickBooks System One models ($200/$100/$50 gift cards per person): new experiences classical ML/GenAI can't do (speed/cost/scale unlocks), realistic evaluation vs baselines required; synthetic accounting data on HuggingFace CL251215/QuickBooks-Hackathon-2026 (disclose modifications).
- MLH: Best Domain (GoDaddy Registry), Gemini API, Snowflake API, ElevenLabs, Vultr, Solana, Tiger Data.
- Browser Use: agent turning goal into web actions (personal workflows, payments, accessibility).
- Creao AI: Best AI-First Disruptor ($2000), Best One-Person Company ($1000), Best Team Empowerment ($500); Launchpad program.
- veri.studio Best use of open-sourced model: post-train/fine-tune a model for a task using Veri.

## Strategy facts
- Teams usually up to 4 people; ~36-48 hr hackathon; one project can be submitted to multiple compatible challenges (stack sponsors that fit naturally).
- Compatibility pitfalls: QNX/Espressif/Even G2 need hardware; Photon beta only live Oct 15; Fetch requires workflow entirely inside ASI:One.
